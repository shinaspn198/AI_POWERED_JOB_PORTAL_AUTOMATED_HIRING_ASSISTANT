## 2. 4-Quarter Scaling Roadmap

### Quarter 1: Real-time Audio Streaming & Low-Latency Voice AI
- **Deliverables:** Full-duplex WebSocket audio streaming (Gemini 3.8 Live / WebRTC) replacing discrete turn-taking.
- **Latency Target:** Sub-400ms time-to-first-audio conversational response.
- **Features:** Voice activity detection (VAD), barge-in handling (candidate interrupts AI naturally), and real-time speech prosody analysis.

### Quarter 2: Computer Vision & Multimodal Affective Computing
- **Deliverables:** In-browser MediaPipe / WebAssembly computer vision models.
- **Metrics:** Gaze fixation ratio, micro-expression valence, head pose stability, and proctoring object detection (second person, unauthorized phones).
- **Compliance:** Real-time client-side feature extraction with zero raw video frame storage on backend servers.

### Quarter 3: Recruiter Agentic Co-Pilot & Candidate AI Coaching
- **Deliverables:**
  - Automated post-interview personalized feedback dossiers for rejected/waitlisted candidates.
  - Live in-call recruiter assistant providing instant technical follow-up questions tailored to candidate code submissions.
- **Analytics:** Enterprise pipeline conversion telemetry, demographic parity monitors, and time-to-hire optimization.

### Quarter 4: Sandboxed Distributed Code Execution & Sandbox Scaling
- **Deliverables:** Ephemeral Firecracker microVM / gVisor sandbox cluster executing multi-file full-stack frameworks (React, Docker Compose, Go, Rust).
- **Scalability:** 10,000+ concurrent live coding sandboxes with <200ms container boot time.
