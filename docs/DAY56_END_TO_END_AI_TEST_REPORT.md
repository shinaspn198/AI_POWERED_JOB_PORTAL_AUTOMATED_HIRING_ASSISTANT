## 4. Key Inconsistencies & Recommendations
1. **Resume Parser Failures on Legacy Formats:** Plain text and non-standard layouts occasionally cause score variations. Recommendation: Implement normalized token extraction (addressed in Day 57).
2. **Confidence Bounds on Short Screening Responses:** Very short answers (<10 words) should trigger clarifying follow-ups rather than immediate negative marking.
3. **Calibrated Thresholds:** Dynamic weighting proved essential to prevent eliminating unconventional high-performing engineers.
