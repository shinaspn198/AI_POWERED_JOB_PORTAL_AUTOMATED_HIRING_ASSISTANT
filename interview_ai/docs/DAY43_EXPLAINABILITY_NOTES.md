# Day 43 – Explainability Notes

## Purpose

These notes explain the existing candidate screening scoring process.

## Screening Score Factors

The screening score evaluates four factors:

- Clarity
- Relevance
- Completeness
- Consistency

Each factor has a maximum score of 25.

The combined maximum score is 100.

## Clarity

Clarity measures how clearly the candidate communicates an answer.

## Relevance

Relevance measures how relevant the candidate's answer is to the
screening question.

## Completeness

Completeness measures whether the candidate provides sufficient
information in the answer.

## Consistency

Consistency measures whether the candidate's answer is consistent with
the candidate's other responses.

## Score Calculation

The four factor scores are added together to produce the question score.

The score is then normalized to a 0–100 scale.

## Candidate Screening Result

The final screening result contains:

- Question scores
- Total score
- Maximum score
- Overall score
- Number of questions evaluated
- Category
- Label
- Description

## Explainability

The scoring factors provide an explanation of how the screening score
was produced.

The system can therefore associate the candidate's screening result
with the scoring factors used to calculate it.

## Scope Note

These notes describe the scoring logic currently present in the reviewed
files. No new scoring formula or explanation mechanism was added for
Day 43.
