# Day 43 – Consent Requirements

## Purpose

This document defines the consent requirements for the HR AI system.

## Consent Requirement

Candidate consent must be obtained before processing candidate data through
the HR AI system.

## Data Processing

Consent applies to the processing of candidate information used by the
recruitment and HR AI system.

This may include information required for:

- Resume processing
- Candidate screening
- AI interview processing
- Candidate evaluation

## Consent Status

The system should maintain whether the candidate has provided consent.

Possible consent states:

- Consent given
- Consent not given

## Consent Record

The consent record should identify:

- Candidate
- Consent status
- Date and time of consent
- Purpose of processing

## Consent Withdrawal

If consent is withdrawn, the system should recognize the withdrawal and
prevent further processing that requires the withdrawn consent.

## Compliance Note

Consent requirements must be applied consistently throughout the HR AI
processing workflow.

This document records the consent requirement for Day 43 ethics and
compliance review.
